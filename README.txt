BOOKNEST - ONLINE BOOKSTORE PROJECT

FILES
- index.html: website structure
- style.css: design and responsive layout
- script.js: search, category filter, sorting, cart and demo checkout
- books.json: book catalogue data

HOW TO RUN
1. Extract this folder.
2. Open the folder in Visual Studio Code.
3. Install the "Live Server" extension if it is not installed.
4. Right-click index.html and choose "Open with Live Server".
5. The website will open in your browser.

IMPORTANT
- The website uses HTML, CSS, JavaScript and JSON.
- The cart is saved in the browser using localStorage.
- Checkout and contact form are demonstrations only.
- No MySQL database, user login, real order processing or payment gateway is connected.
- Internet is required for Google Fonts and remote book cover images.
